# MCS-202 Computer Organisation Study Studio

A React study app covering all 16 units across the four IGNOU course blocks.
It maps 227 section lessons from the books. Each lesson has a guided reader
that reveals the complete section text in short recall steps, an interactive
visual model, and access to the intact section text. Unit pages also include a
searchable source reader, retrieval questions with feedback, exam answer
prompts, and a saved topic-by-topic mastery checklist. The original PDF for the unit's
block is included for figures, diagrams, tables, and page layout.

The 16 source readers contain approximately 134,000 extracted words from the
provided PDFs. The four original PDFs are bundled under `public/source/pdfs/`.

## Run locally

```bash
npm install
npm run dev
```

Open the local address shown by Vite. To create and preview a production build:

```bash
npm run build
npm run preview
```

Progress is stored in the browser's local storage.
